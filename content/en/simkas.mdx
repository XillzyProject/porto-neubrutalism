title: "SIMKAS – Group Cash Management System"
description: "A responsive web app and PWA for managing group finances in a transparent and structured way — built for KKN groups, student organizations, and committees of 10–100 members. It features three roles (Admin, Treasurer, Member) with centralized transaction records, cash periods, automated dues tracking with Paid/Partial/Overdue statuses, in-app notifications, and a demo mode with periodic data resets. All heavy logic — security, triggers, and cron jobs — is handled at the PostgreSQL database level (RLS) instead of the application server."
