description: "Aplikasi web dan PWA untuk mengelola kas kelompok secara transparan dan terstruktur — dirancang untuk komunitas KKN, organisasi mahasiswa, hingga kepanitiaan dengan 10–100 anggota. Mengusung tiga peran (Admin, Bendahara, Anggota) dengan pencatatan transaksi terpusat, periode kas, tagihan otomatis dengan status Lunas/Sebagian/Terlambat, notifikasi in-app, hingga mode demo dengan reset data berkala. Seluruh logic berat — keamanan, trigger, dan cron — ditangani di level database PostgreSQL (RLS), bukan di server aplikasi."
